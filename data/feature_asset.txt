Can see 'Facilities' menu item ¦ Allows the user to see the Facilities menu item in the web app.
Can see 'Equipment' menu item ¦ Allows the user to see the Equipment menu item in the web app.
Can see 'Tools' menu item ¦ Allows the user to see the Tools menu item in the web app.
Can see 'CMMS Settings' menu item ¦ Allows the user to access CMMS Settings in the web app.
@Page
Asset ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to see and edit individual assets and their detail pages, including setting the asset online or offline.
Assets ¦ Can Access Has 'New' Button Has 'Edit' Menu Item Has 'Print' Button Has 'Delete' Button Has 'Export' Button Has 'Import' Button ¦ Allows the user to access the list of assets.
Asset Business ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to add businesses to assets under the Business tab of the asset details page. Prerequisite permissions: Asset page permissions Assets page permissions
Asset Categories ¦ Can Access Has 'New' Button Has 'Edit' Menu Item Has 'Print' Button Has 'Delete' Button Has 'Export' Button Has 'Import' Button ¦ Allows the user to adjust how categories are organized in the asset hierarchy (which categories are parents and children of each other) and assign assets to categories in CMMS Settings > Asset Categories tab. Prerequisite permissions: CMMS Settings page permissions Asset page permissions Assets page permissions
Asset Category ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to add new categories, edit asset category names, adjust category order in the hierarchy, and update barcode format for categories at CMMS Settings > Asset Categories tab. Prerequisite permissions: CMMS Settings page permissions Asset page permissions Assets page permissions
Asset Event ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to add an asset event to an asset or a scheduled maintenance. Users with this permission can add asset events on the asset details page > Metering/Events tab > Most Recent Asset Events header > Add button. Prerequisite permissions: CMMS Settings page permissions Asset page permissions Assets page permissions
Asset Event Types ¦ Can Access Has 'New' Button Has 'Edit' Menu Item Has 'Print' Button Has 'Delete' Button Has 'Export' Button Has 'Import' Button ¦ Expected behavior: Allows the user to add and edit event types at CMMS Settings > Lookup tables tab > Asset Event Types header. Prerequisite permissions: CMMS Settings page permissions Asset page permissions
Asset Events History ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to access the Asset Events History page, where the user can view and edit an asset's recorded asset events. To access the Asset Events History page, navigate to an asset details page > Metering/Events tab > Most Recent Asset Events header and click a recorded event. Prerequisite permissions: Asset page permissions Assets page permissions
Asset File ¦ Can Access Has 'Save' Has 'Print' Button Has 'Import' Button ¦ Allows the user to add and edit files to assets. Users without this permission can still add basic files to assets, but they can't change the file type. Users with this permission can click on an added file (Asset > Files tab) and change the file type, including add an asset default image. Prerequisite permissions: Asset page permissions Assets page permissions
Asset Filter ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Expected behavior: Allows the user to use the list of filters on the asset list page, including adding and deleting the custom filters that are available to all users of the CMMS. Prerequisite permissions: Assets page permissions
Asset Parts Supplies ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Allows the user to add parts and supplies to an asset from the asset details page under the Parts/BOM tab. Prerequisite permissions: Asset page permissions Assets page permissions
Asset Tag List ¦ Can Access Has 'Save' Button Has 'Print' Button Has 'Import' Button ¦ Expected behavior: Allows the user to access the Print Asset Tag button on the assets list page to print labels for assets. Prerequisite permissions: Assets page permissions
Assigned Assets ¦ Can Access Has 'New' Button Has 'Edit' Menu Item Has 'Print' Button Has 'Delete' Button Has 'Export' Button Has 'Import' Button ¦ Allows the user to access the Assigned Assets page, which shows assets assigned to the user and to their direct reports. Prerequisite permissions: Can See 'Assigned Assets' menu permission Asset page permissions Assets page permissions
Import Asset Event Types ¦ Can Access ¦ Allows the user to bulk import asset event types (Settings > Import > Asset Event Types).
Import Asset Events ¦ Can Access ¦ Allows the user to bulk import asset event types (Settings > Import > Asset Events).
Import Assets ¦ Can Access ¦ Allows the user to bulk import assets (Settings > Import > Asset Events).
